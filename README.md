# Beauty CRM

Локальная CRM и расписание для бьюти-мастера: записи, клиенты, свободные окна, финансы и статистика.
Работает прямо в браузере и без интернета, а на iPhone ставится как приложение.

**Статус:** в разработке. ТЗ лежит в [`docs/SPEC.md`](docs/SPEC.md), прогресс — в [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Как открыть на компьютере

```bash
python3 -m http.server 8000
```
Затем откройте http://localhost:8000

## Как открыть на iPhone по ссылке

1. В репозитории на GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
2. Через 1–2 минуты появится ссылка вида `https://mjo11nir.github.io/dicrm/`.
3. Откройте её в Safari, нажмите **«Поделиться» → «На экран „Домой“»**.

Данные хранятся только на вашем устройстве. Регулярно делайте резервную копию: «Другое → Резервная копия».
