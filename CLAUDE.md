# Инструкции для Claude Code

Этот репозиторий — **Beauty CRM**, локальная PWA-CRM для бьюти-мастера (клон интерфейса Master Up со своим брендингом).

- Полное ТЗ: `docs/SPEC.md`. Прочитай его целиком перед началом работы.
- Скриншоты-образцы: `docs/screenshots/`. Открой и посмотри каждый перед тем, как делать соответствующий экран. Если ТЗ и скриншот расходятся, верь скриншоту.
- Прогресс: `docs/PROGRESS.md` — отмечай там, что сделано по этапам, и обновляй после каждого этапа.

## Жёсткие правила

1. Чистые HTML + CSS + JavaScript (ES-модули), без сборщиков и npm в рантайме. Библиотеки только по CDN: Dexie.js, Chart.js, html2canvas.
2. Никаких серверов, SQL, Docker, фреймворков (React/Next/Nest/Flutter), регистрации и логинов. Все данные — в IndexedDB через `js/db.js`.
3. Работай по этапам из раздела 11 ТЗ. Этап считается готовым, когда приложение открывается и всё сделанное в нём работает. После этапа сделай коммит с понятным сообщением на русском.
4. Никаких нерабочих кнопок. Что требует сервера — бейдж «Скоро» с пояснением.
5. Не используй логотип и название Master Up. Иконки бери из Lucide или Tabler (inline SVG).
6. Свободные окна считаются только в `js/utils/slots.js`, тесты лежат в `tests/slots.test.html`.
7. Перед завершением этапа запусти локальный сервер (`python3 -m http.server 8000`), открой приложение и проверь, что в консоли нет ошибок.
8. Интерфейс и комментарии в коде — на русском.

## Как запустить

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Публикация: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
