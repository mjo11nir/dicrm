# ТЗ: Beauty CRM — локальная CRM и расписание для бьюти-мастера

Веб-приложение (PWA) для бьюти-мастера: CRM и расписание записей. Это должен быть максимально точный клон
интерфейса и логики приложения Master Up – Scheduling App по скриншотам из `docs/screenshots/`: та же
структура экранов, расположение элементов, отступы, цвета, шрифты и поведение. Но у приложения своё название —
**«Beauty CRM»** (можно поменять в настройках), свой простой логотип и иконки из открытого набора (Lucide или Tabler).
Логотип и название Master Up не используются.

## Значения по умолчанию

- Мастер работает один, без сотрудников. Услуги: маникюр и педикюр.
- Валюта €, язык русский, неделя начинается с понедельника, формат времени 24 ч.
- Основное устройство — iPhone (Safari и установка на экран «Домой»).
- Текст бейджа под именем: «PRO» (меняется в профиле).

## 0. Главный принцип — всё работает локально

- Приложение открывается по ссылке в браузере и ставится на iPhone через Safari («На экран „Домой“»), после этого выглядит как настоящее приложение: на весь экран, без адресной строки.
- Работает без сервера и без интернета. Все данные хранятся в IndexedDB через Dexie.js (подключить по CDN).
- **НЕ использовать:** SQL, PostgreSQL, Redis, Docker, Node-сервер, NestJS, Next.js, Flutter, React Native, сборщики (vite/webpack), npm-зависимости в рантайме, регистрацию и логины.
- Используются чистые HTML, CSS и JavaScript (ES-модули). Chart.js, Dexie и html2canvas подключаются по CDN, а service worker кэширует их для работы без интернета.
- Структура проекта:
  ```
  /index.html
  /manifest.json
  /sw.js                    (service worker, работа без интернета)
  /css/styles.css
  /js/app.js                (роутер вкладок и экранов)
  /js/db.js                 (вся работа с данными только здесь — позже сюда добавится синхронизация с сервером)
  /js/screens/*.js          (один файл на экран)
  /js/components/*.js       (переиспользуемые компоненты)
  /js/utils/*.js            (даты, деньги, расчёт свободных окон)
  /icons/                   (иконки приложения 180×180, 192×192, 512×512)
  /tests/                   (тесты, открываются в браузере)
  ```
- Каждая кнопка должна работать. Никаких заглушек и кнопок «для красоты». Если функцию без сервера сделать нельзя, кнопка видна, но помечена бейджем «Скоро», а при нажатии объясняет, что функция появится после подключения сервера.

## 1. Дизайн-система

Общий стиль — нативный iOS 17: системный шрифт (`-apple-system, "SF Pro Display", "SF Pro Text", sans-serif`),
крупные жирные заголовки, белые скруглённые карточки на светло-сером фоне, тонкие разделители, плавные анимации.

Цвета (CSS-переменные):
```
--primary:        #9137E8   фиолетовый: активные вкладки, ссылки, кнопки, «+»
--bg:             #F2F1F7   фон экранов
--surface:        #FFFFFF   карточки
--text:           #111111
--text-secondary: #8A8A8E
--separator:      #E5E5EA
--teal:           #078EA7   сегодняшний день в месяце, строка «Сегодня …» и часы работы
--red:            #E5484D   нерабочие дни в календаре
--green:          #28B84A   рост «+N», точки свободных окон, часть полосы финансов
--pink:           #EB3485   колокольчик напоминания
--orange:         #F0A626   иконки группы «График/Онлайн-запись/Лист ожидания»
Пастельные подложки иконок:
  жёлто-бежевая #F6E5BE, зелёная #BFEFC8, серая #E3E3E8, розовая #FDE1EC, сиреневая #ECDDFC
```

- Скругления: карточки 16px, плитки быстрых действий 22px (squircle), кнопка «Отправить» — капсула (999px).
- Отступы: поля экрана 16px, расстояние между карточками 12px, внутренние отступы карточек 16px.
- Тени: карточки на Главной — очень мягкие (`0 2px 12px rgba(0,0,0,.04)`). В списках настроек теней нет.
- Тёмная тема: та же структура, фон #000, карточки #1C1C1E, разделители #38383A. Включается по системной теме и вручную в «Оформлении».

**Нижняя панель вкладок** (как на всех скриншотах):
- 4 вкладки: «Главная» (иконка из 4 квадратов), «Расписание» (календарь с точками), «Чаты» (облачко с тремя точками), «Другое» (три горизонтальные линии).
- Иконка над подписью, подпись 11–12px. Активная вкладка фиолетовая, неактивные серые #8E8E93.
- Фон панели полупрозрачный, с размытием (`backdrop-filter: blur`), сверху тонкая линия. Учитывать `safe-area-inset-bottom`.
- Каждая вкладка помнит своё состояние: прокрутку и открытый подэкран.

**Переиспользуемые компоненты:** TabBar, NavBar (кнопка «назад» — фиолетовая стрелка, заголовок по центру), LargeTitle,
SegmentedControl (серый фон, белый «бегунок» с тенью), GroupedList (группа строк iOS: иконка, текст, значение, шеврон «>»),
IconTile, WeekStrip, MonthCalendar, AppointmentRow, FreeSlotRow, StatCard, BottomSheet (выезжает снизу, есть «ручка»,
закрывается свайпом вниз), EmptyState, Toast с кнопкой «Отменить».

## 2. Экран «Главная» (`01-home.jpg`)

Фон: мягкий переливающийся пастельный градиент на весь экран (розовый, сиреневый, мятный, лёгкий жёлтый, плавные пятна).
В «Оформлении» его можно выключить.

Сверху вниз:
1. **Шапка-карточка** (полупрозрачная белая, размытие фона):
   - слева круглая аватарка 56px с белой обводкой;
   - справа от неё имя мастера жирным 20px, под ним чёрный бейдж-капсула с белым текстом статуса;
   - справа иконки: «вид недели» (столбцы), «календарь» (открывает Расписание), колокольчик (открывает Оповещения);
   - при прокрутке шапка сжимается, имя уходит, вместо него появляется дата выбранного дня («Вт, 10 нояб.»).
2. **Полоса недели** (внутри той же карточки):
   - буквы дней П В С Ч П С В; у нерабочих дней (по графику) буквы и числа красные;
   - выбранный день — число в чёрном круге с белым текстом; сегодняшний день, если он не выбран, — фиолетовое число;
   - свайп влево/вправо листает недели.
3. **Список записей выбранного дня** (в той же карточке):
   - строка: слева время начала 18px, под ним время конца серым; справа имя клиента 18px, под ним услуга серым в одну строку с многоточием;
   - нажатие открывает карточку записи;
   - если записей нет — серый текст «Нет записей» и ссылка «Создать»;
   - внизу карточки после разделителя по центру серым: «Выручка: €135» (сумма записей дня).
4. **Отдельная белая карточка-кнопка:** фиолетовый круг с «+» и жирный текст «Создать запись».
5. **Две карточки рядом** (по 50%):
   - «Клиенты»: заголовок жирный, крупное число, «Всего в базе», ниже зелёным «+N» и текст «в ноябре» (новые клиенты за текущий месяц);
   - «Финансы»: заголовок, название месяца, крупная сумма месяца, ниже полоса прогресса из двух частей: зелёная — уже получено (завершённые записи), фиолетовая — запланировано (будущие записи месяца).
   - Нажатие открывает Клиентов или Статистику.
6. **Карточка быстрых действий:** 4 плитки в ряд, у каждой квадратная пастельная подложка 72px с иконкой и подпись снизу в 2 строки:
   - «Создать запись» — жёлто-бежевая подложка, оранжевая иконка календаря с «+»;
   - «Свободные окна» — жёлто-бежевая, оранжевый календарь;
   - «Уведомления» — зелёная, зелёное облачко «…»;
   - «Помощь» — серая, серый круг с «?».

## 3. Вкладка «Расписание» (`02-schedule-month.jpg`)

Сверху по центру переключатель (SegmentedControl): «День | Неделя | Лента».

**Режим «День»:**
1. Заголовок месяца фиолетовым «Ноябрь ^»: нажатие сворачивает календарь в одну неделю и разворачивает обратно (стрелка поворачивается).
2. Сетка месяца:
   - строчные буквы дней «п в с ч п с в» серым;
   - дни соседних месяцев бледные;
   - нерабочие дни (выходные по графику и отпуск) — красные числа;
   - сегодняшний день — число в бирюзовом круге (#078EA7) с тенью, белый текст;
   - выбранный день, если это не сегодня, — светлый фиолетовый круг;
   - под числом до 2 точек: серая — в этот день есть записи, зелёная — есть свободные окна;
   - свайп листает месяцы.
3. Строка под календарём бирюзовым цветом: слева «Сегодня Чт, 12 нояб.» (или просто дата выбранного дня), справа рабочие часы дня «09:00 - 19:00 >». Нажатие на часы позволяет изменить часы только для этого дня.
4. Лента дня (белый фон), карточки с тонкой серой рамкой и скруглением 12px:
   - **Запись:** слева время начала (чёрным) и конца (серым) в столбик; в центре имя клиента, услуга серым с многоточием, цена «€45,00»; справа круглая аватарка клиента (серый силуэт, если нет фото). Если напоминание клиенту отправлено, на аватарке розовый кружок с белым колокольчиком.
   - **Свободное окно** (считается автоматически между записями, в рабочих часах): слева фиолетовое время начала «18:15»; справа фиолетовым жирным «создать запись или перерыв», под ним серым «свободно: 45 мин». Нажатие открывает лист выбора «Запись / Перерыв» с подставленным временем.
   - **Перерыв:** серая карточка «Перерыв 13:00–14:00».
   - Записи, окна и перерывы идут строго по времени.
5. Нижняя закреплённая панель над вкладками: слева фиолетовая лупа (поиск по записям и клиентам), по центру мелко серым «Выручка за день» и под ним жирно «€45,00», справа фиолетовая ссылка «Сегодня» (возврат к сегодняшнему дню).

**Режим «Неделя»:** 7 колонок с часами по вертикали (как в Календаре iOS), записи — цветные блоки по высоте длительности; нерабочие часы затемнены; над каждым днём сумма выручки.

**Режим «Лента»:** все будущие записи списком, сгруппированы по датам с заголовками («Пт, 13 нояб.»), с поиском и фильтром по статусу.

## 4. Запись (создание и карточка)

**Форма создания в BottomSheet:**
- Клиент: поиск по имени или телефону, кнопка «+ новый клиент» прямо в форме.
- Услуги: можно выбрать несколько, длительность и цена складываются автоматически.
- Дата, время начала; длительность можно поменять вручную; время конца считается само.
- Цена, скидка (% или сумма), предоплата, комментарий.
- Повтор записи: нет / каждую неделю / каждые 2 / 3 / 4 недели.
- Проверка пересечений: если время занято или вне рабочего графика — красное предупреждение и кнопка «Всё равно сохранить».

**Карточка записи:** клиент (кнопки «Позвонить», «WhatsApp», «Telegram»), услуги, время, цена, оплачено/остаток.
Статусы: Запланирована, Подтверждена, Завершена, Не пришёл, Отменена.
Кнопки: «Перенести», «Изменить», «Отменить», «Завершить и принять оплату» (наличные / карта / перевод),
«Отправить напоминание» (открывает WhatsApp с готовым текстом по шаблону и ставит колокольчик на аватарку).

## 5. Вкладка «Чаты»

Без сервера настоящую переписку сделать нельзя, поэтому:
- список клиентов, отсортированный по последнему контакту, с аватаркой, именем, последней записью и датой;
- нажатие открывает экран клиента: история отправленных сообщений (сохраняется локально) и быстрые шаблоны «Напоминание», «Подтверждение», «Свободные окна», «Поздравление с ДР», «Пора записаться снова»;
- отправка идёт через ссылку wa.me / t.me с подставленным текстом, отправленное сообщение сохраняется в истории.

## 7. Профиль → Настройки (`04-profile-settings.jpg`)

NavBar: фиолетовая «<» слева, заголовок «Профиль». Сверху блок профиля: аватарка (можно загрузить фото), имя, телефон,
адрес, текст бейджа. Ниже крупный заголовок «Настройки» и группы iOS (белая карточка, внутри строки, разделитель
с отступом от иконки). У каждой строки цветная квадратная иконка 30px со скруглением 8px и белым значком, затем текст и серый шеврон «>».

- **Группа 1 (оранжевые иконки):**
  - «График и место работы»: рабочие дни недели, часы, перерывы, отпуска/выходные по датам, шаг слотов (15/30/60/120 мин), места работы (название + адрес).
  - «Онлайн-запись» — бейдж «Скоро» (нужен сервер).
  - «Лист ожидания» — справа значение «Вкл/Выкл». Это список клиентов, которые ждут окно (желаемые даты, время, услуга). Когда появляется свободное окно, клиент подсвечивается и можно отправить ему сообщение.
- **Группа 2:** «Услуги и товары» (фиолетовая иконка): услуги по категориям — название, длительность, цена, перерыв после, интервал повторного визита (например 21 день), активна/скрыта; товары — цена, себестоимость, остаток.
- **Группа 3:** «Web-страница» (розовая): редактор визитки (описание, услуги с ценами, фото из Галереи, контакты, цвет) → предпросмотр и кнопка «Скачать HTML».
- **Группа 4:** «Клиенты» (розовая): импорт и экспорт CSV, поиск дубликатов.
- **Группа 5 (зелёные иконки):**
  - «Уведомления для клиентов»: шаблоны текстов с переменными `{имя}`, `{дата}`, `{время}`, `{услуга}`, `{адрес}`, `{цена}`.
  - «Оповещения»: напоминания для меня — о записях на завтра, днях рождения, клиентах, которым «пора снова».
  - «Синхронизация с календарем»: экспорт записей в .ics для Календаря iPhone.
- **Группа 6 (серые иконки):**
  - «Оформление»: тема (Авто/Светлая/Тёмная), фон Главной вкл/выкл, акцентный цвет.
  - «Язык и регион»: русский/английский/турецкий, валюта (€, ₺, $, ₽), формат времени, первый день недели.
- **Группа 7:** «Синхронизация» — бейдж «Скоро».

## 8. Свободные окна (`05-free-slots.jpg`, `06-free-slots-share.jpg`) — важнейший экран

Открывается модально снизу. NavBar: слева фиолетовое «Закрыть», по центру «Свободные окна».
Переключатель на всю ширину: «Поделиться | Найти и записать».

**Вкладка «Поделиться»:**
1. Серый поясняющий текст 13px: «Укажите, когда у вас есть свободное для записи время. Для этого выберите нужный временной период…»
2. Группа строк (белый фон, на всю ширину, тонкие разделители):
   - место: название крупно, адрес серым ниже, «>»;
   - «Период»: справа серым «1 дек. - 28 дек.», «>» (быстрые варианты: эта неделя, следующая неделя, этот месяц, следующий месяц, свой);
   - «Вид»: «Изображение (соцсети)» / «Текст»;
   - «Цветовая тема»: справа квадратик 36px с градиентом выбранного цвета (6 вариантов: фиолетовый, розовый, бирюзовый, зелёный, оранжевый, графит).
3. Заголовок раздела серым капсом «СВОБОДНЫЕ ОКНА ПО ДНЯМ».
4. **Карточка-превью** (именно она превращается в картинку):
   - шапка с градиентом цветовой темы (от #8A2BE2 к #B57BF5 для фиолетовой): слева белый круг 88px с логотипом/аватаркой, справа белым: имя жирно, телефон, место, адрес (последние строки полупрозрачные); справа в шапке полупрозрачная надпись «Записывайтесь!» и крупный бледный водяной знак логотипа;
   - тело белое: заголовок жирным серым «Свободное время для записи:», затем строки по дням: слева жирно «вт, 1 дек.», справа времена «9:00  11:00  15:00  17:00»; между строками пунктирные разделители;
   - дни без свободного времени не показываются.
5. Большая фиолетовая кнопка-капсула «Отправить» на всю ширину. Она рендерит карточку в PNG (html2canvas, масштаб 3x) и открывает системное меню «Поделиться» (`navigator.share` с файлом). Если share недоступен — скачивает PNG. В режиме «Текст» копирует текст и открывает меню «Поделиться».

**Алгоритм свободных окон** (`js/utils/slots.js` — единственное место, где они считаются, его же использует Расписание):
- берём рабочие часы дня из графика с учётом исключений и отпусков;
- вычитаем записи (кроме отменённых), перерывы и перерыв после услуги;
- оставшиеся интервалы режем на слоты по стандартной длительности (настройка, по умолчанию 2 часа: 9:00, 11:00, 13:00…);
- прошедшее время сегодня не показываем;
- нерабочие дни пропускаем.
- Тесты для этой функции — в `/tests/slots.test.html` (открываются в браузере, показывают ✅/❌).

**Вкладка «Найти и записать»:** выбор услуги и периода → список ближайших свободных слотов, сгруппированных по дням → нажатие на слот открывает форму записи с подставленными датой, временем и услугой.

## 9. Остальные разделы

- **Клиенты:** алфавитный список с буквенными разделами, поиск, фильтры (новые, постоянные, давно не были, с ДР в этом месяце). Карточка клиента: фото, имя, телефон, мессенджеры, ДР, заметки, теги, все визиты, сумма трат, средний чек, последний визит, следующая запись, личная скидка, фото работ.
- **Статистика:** период (неделя / месяц / год / свой); выручка (линейный график по дням), число записей, завершённые, отмены, неявки (%), средний чек, новые и вернувшиеся клиенты, топ услуг (столбцы), доходы против расходов, прибыль. Chart.js в цветах дизайн-системы. Предоплату и итоговую оплату не считать дважды.
- **Расходы:** быстрый ввод (сумма, категория-плитка, дата, комментарий), категории: Материалы, Аренда, Реклама, Обучение, Инструменты, Другое; итоги по месяцам.
- **Галерея:** загрузка фото с телефона (сжимать до 1600px, хранить в IndexedDB как Blob), сетка 3 колонки, подписи, теги «до/после», привязка к клиенту и услуге.
- **Отзывы:** добавление вручную (клиент, оценка 1–5 звёзд, текст, дата), средняя оценка сверху.
- **Помощь:** короткий FAQ и инструкция «Как установить на iPhone».
- **Резервная копия:** экспорт всех данных (включая фото) в один JSON-файл и импорт обратно. Раз в 7 дней на Главной напоминание сделать копию.

## 10. Данные и технические требования

- Таблицы IndexedDB: profile, locations, schedule, scheduleExceptions, services, serviceCategories, products, clients, appointments, breaks, payments, expenses, waitlist, templates, messages, gallery, reviews, settings, outbox.
- Деньги — целые числа в центах; даты — ISO; время с учётом часового пояса устройства.
- Формат: «€2.345», «€45,00», даты по-русски: «Вт, 10 нояб.», «чт, 19 нояб.».
- Анимации: переходы экранов как в iOS (сдвиг вправо/влево), BottomSheet выезжает снизу, при нажатии карточки немного уменьшаются (scale .97).
- Удобно пальцем: зоны нажатия не меньше 44px, без зума при фокусе в поле (font-size ≥ 16px в input).
- PWA: manifest (standalone, theme-color #F2F1F7), apple-touch-icon, service worker кэширует все файлы. При первом открытии в Safari — подсказка, как добавить приложение на экран «Домой».
- Демо-данные при первом запуске: 25 клиентов, 6 услуг маникюра/педикюра с ценами в €, записи на прошлый и будущий месяц, несколько расходов и отзывов. В «Резервной копии» кнопка «Удалить демо-данные».
- Без ошибок в консоли, код с комментариями на русском.

**Подготовка к будущей синхронизации с сервером (сам сервер сейчас НЕ делать):**
- id всех записей — UUID (`crypto.randomUUID()`), не числа по порядку;
- у каждой записи поля `createdAt`, `updatedAt` и `deleted` (мягкое удаление вместо настоящего);
- `db.js` при каждом изменении добавляет запись в таблицу `outbox` (что изменилось и когда);
- в настройках есть раздел «Синхронизация» с бейджем «Скоро».
